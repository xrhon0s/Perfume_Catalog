# Datos de ubicaciones

`colombiaLocations.json` contiene una copia local y compacta de departamentos,
municipios y códigos DANE para el formulario de entrega. Se extrajo de
`colombia-cities@1.0.0` (licencia MIT) y no requiere esa dependencia ni una API
en producción.

La copia fue generada el 26 de julio de 2026. Conviene contrastarla
periódicamente con DIVIPOLA antes de incorporar cambios territoriales.
